# پروژه تمرین SQLAlchemy

این پروژه شامل تمرین‌هایی برای یادگیری و کار با کتابخانه SQLAlchemy در پایتون است.

## فایل‌های پروژه
- app.py, app1.py, app2.py: فایل‌های اصلی کدهای پایتون
- StudentData.db و فایل‌های مشابه: دیتابیس‌های ساخته شده
- requirements.txt: لیست کتابخانه‌های مورد نیاز
